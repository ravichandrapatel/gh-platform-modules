## Requirements

| Name | Version |
|------|---------|
| <a name="requirement_terraform"></a> [terraform](#requirement\_terraform) | >= 1.10.0 |
| <a name="requirement_aws"></a> [aws](#requirement\_aws) | >= 5.0 |

## Inputs

| Name | Description | Type | Default | Required |
|------|-------------|------|---------|:--------:|
| <a name="input_name"></a> [name](#input\_name) | The name of the SAML provider. | `string` | n/a | yes |
| <a name="input_saml_metadata_document"></a> [saml\_metadata\_document](#input\_saml\_metadata\_document) | An XML document generated by an identity provider that supports SAML 2.0. Required if saml\_metadata\_secret\_id is not provided. | `string` | `null` | no |
| <a name="input_saml_metadata_secret_id"></a> [saml\_metadata\_secret\_id](#input\_saml\_metadata\_secret\_id) | The ID or ARN of the secret in Secrets Manager containing the SAML metadata document. If provided, this takes precedence over saml\_metadata\_document. | `string` | `null` | no |
| <a name="input_saml_metadata_secret_key"></a> [saml\_metadata\_secret\_key](#input\_saml\_metadata\_secret\_key) | The key in the Secrets Manager secret (JSON) that contains the SAML metadata document. If not provided, the entire secret string is used. | `string` | `null` | no |
| <a name="input_tags"></a> [tags](#input\_tags) | A map of tags to add to all resources. | `map(string)` | `{}` | no |

## Outputs

| Name | Description |
|------|-------------|
| <a name="output_arn"></a> [arn](#output\_arn) | The ARN assigned by AWS for this SAML provider. |
| <a name="output_name"></a> [name](#output\_name) | The name of the SAML provider. |
| <a name="output_valid_until"></a> [valid\_until](#output\_valid\_until) | The expiration date and time for the SAML provider. |
